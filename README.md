# Gestão Instituto Íris

Painel de gestão das aulas gratuitas do Instituto Íris (Éden): alunos com foto, turmas,
chamada (frequência), inscrições e finanças (entradas e saídas).

- `iris.html` — a página inteira (HTML, CSS e JS em um arquivo), publicada como link do Claude.
- `gestao/` + `PUBLICAR.md` — a mesma gestão publicada fora do Claude (Firebase), com login por e-mail.
- Os dados ficam no banco do próprio link (compartilhado com quem tiver acesso de Colaborador ou Editor).
- Aberto fora do Claude, o arquivo mostra dados de exemplo e não salva nada.
